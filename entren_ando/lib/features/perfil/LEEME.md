# features/perfil

Dueño: Axel. Historia: ENT-18 (datos biométricos, objetivos y equipo).

`pantalla_perfil.dart` es la pantalla inicial del proyecto base. En modo debug trae el botón
"Reiniciar datos de prueba" y "Ver componentes del diseño", que sirven a todo el equipo: no
los quites. El selector de Tema (claro u oscuro) usa `modoTemaProvider` de lib/core/tema.
