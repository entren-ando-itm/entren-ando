# core/componentes

Dueño: Pablo (ENT-12). Las piezas del diseño que usan todas las pantallas: encabezados,
tarjetas, botones, campos, avisos, semáforo, barras, filas de ajustes, hoja inferior y la barra
de navegación. Se importan junto con el tema en una sola línea:

```dart
import 'package:entren_ando/core/diseno.dart';
```

Las reglas y la tabla de componentes están en AGENTS.md (sección "Diseño visual"). Para verlos
todos en la app: Perfil → Modo de prueba → "Ver componentes del diseño" (`galeria_componentes.dart`).

Si a tu pantalla le falta una pieza, coméntalo en el daily antes de crearla: si se aprueba, se
agrega aquí para todo el equipo y se suma a la galería.
